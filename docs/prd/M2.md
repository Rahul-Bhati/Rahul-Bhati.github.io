# PRD — M2: Auth + protected `/admin`

## Goal
Only Rahul can reach `/admin`. A secure single-admin login: validated form, hashed-password check, signed session cookie, route guard, logout.

## Why
The CMS, dashboard, and link editor are owner-only. Auth must come before any admin surface exists.

## Scope
- **Secrets (env):** `ADMIN_EMAIL`, `ADMIN_PASSWORD_HASH` (bcrypt), `AUTH_SECRET` (≥32 bytes). Password never stored in plaintext or code.
- `scripts/hash-password.ts` — `tsx scripts/hash-password.ts '<password>'` prints the bcrypt hash to paste into `.env.local`.
- `src/lib/auth.ts` — `jose` HS256 sign/verify; `createSession`, `getSession`, `destroySession`; cookie `__Host-session` httpOnly, Secure, SameSite=Lax, `path=/`, ~7-day expiry with sliding refresh.
- `src/lib/rate-limit.ts` — fixed-window limiter keyed by IP (in-memory; swappable). Lockout after N failures.
- `/admin/login` (`src/app/admin/login/page.tsx`) — client form, zod schema, inline field errors, disabled-while-submitting. Calls `login` server action.
- `login`/`logout` server actions (`src/app/admin/actions.ts`): timing-safe `bcrypt.compare`, **generic** "Invalid email or password" (no enumeration), rate-limit check, CSRF via `origin`/`sec-fetch-site` validation, set/clear cookie, redirect.
- `middleware.ts` — verify session for `/admin/:path*` except `/admin/login`; redirect unauthenticated → `/admin/login?next=…`; add security headers (`X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, basic CSP).
- `src/app/admin/layout.tsx` — `robots: { index:false, follow:false }`, admin chrome + sign-out.
- `src/app/admin/page.tsx` — placeholder dashboard shell (filled in M3).

## Out of scope
Analytics data/charts (M3). Any content editing (M4+).

## Acceptance tests
1. Visiting `/admin` while logged out → redirect to `/admin/login`.
2. Empty/invalid email → inline validation error, no submit.
3. Wrong password → generic error; repeated wrong attempts → lockout message.
4. Correct credentials → redirect to `/admin`, session cookie set (httpOnly).
5. Sign out → cookie cleared, `/admin` redirects again.
6. `/admin*` pages emit `noindex`.
7. Edge runtime: middleware verifies JWT via `jose` (no Node-only API).

## Gate (exit)
All 7 tests pass → unlocks **M3**.
