# PRD — M4: Blog CMS (+ media upload) & public blog pages

## Goal
Create, edit, publish, and delete blog posts with image + video attachments; render SEO-ready public pages from the DB.

## Why
Core ask: Rahul writes posts in his own admin, attaches media, and they appear on the portfolio with strong per-post SEO.

## Scope
- **Storage:** Supabase Storage bucket `media` (public read). `src/lib/storage.ts` + `uploadMedia` server action: validate type (image/*, video/mp4|webm) and size (e.g. ≤8MB image, ≤100MB video), upload via service-role client, return public URL, persist `Media` row.
- **Uploader:** `src/components/admin/media-uploader.tsx` — drag/drop or pick, preview, progress, insert into content or set as cover.
- **Editor pages:**
  - `/admin/blog` — list (status, date, edit/delete).
  - `/admin/blog/new` & `/admin/blog/[id]` — form: title, slug (auto from title, editable), excerpt, **markdown** body w/ media insert, cover image, status (draft/published), crossPosts editor (platform+label+href), SEO override fields.
- **Actions** (`src/app/admin/blog/actions.ts`): `createPost`/`updatePost`/`deletePost`/`publishPost` — auth-guarded, zod-validated, `revalidatePath` on `/blog` + `/blog/[slug]`.
- **Auto-SEO:** `src/lib/seo.ts`:
  - `deriveSeo(post)` — fills `metaTitle` (title), `metaDescription` (excerpt or first paragraph, ≤155 chars, stripped), `keywords` when blank.
  - `buildPostMetadata(post)` → Next `Metadata` (title/description/canonical/openGraph/twitter/keywords/robots).
  - `postJsonLd(post)` → `BlogPosting` schema.
- **Public:**
  - `/blog` (`src/app/blog/page.tsx`) — list **published** posts from DB.
  - `/blog/[slug]` (`src/app/blog/[slug]/page.tsx`) — `generateMetadata` via `buildPostMetadata`; sanitized markdown render (`react-markdown` + `remark-gfm` + `rehype-sanitize`); inline media; BlogPosting JSON-LD; `generateStaticParams` for published slugs.
  - Drawer (`detail-drawer.tsx`) reads DB content for quick view (keeps existing UX).

## Out of scope
Projects CRUD (M5). Sitemap/OG-image/llms.txt (M6).

## Acceptance tests
1. Create draft → not visible on public `/blog`.
2. Upload an image and a video in the editor → both stored, public URLs work.
3. Publish → appears on `/blog` and at `/blog/<slug>`.
4. `view-source` of `/blog/<slug>` shows correct `<title>`, meta description, OG tags, and BlogPosting JSON-LD.
5. Edit updates the live page; delete removes it.
6. Empty SEO fields → sensible auto-generated metadata; overrides win when set.

## Gate (exit)
Tests pass → unlocks **M5**.
