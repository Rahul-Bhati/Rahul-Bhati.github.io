# PRD — M6: SEO/GEO hardening + ship to Vercel

## Goal
Maximize discoverability for both search engines and generative engines (GEO), then deploy to production.

## Why
The whole point of per-item metadata is to rank and be cited. M6 wires the site-wide signals and ships.

## Scope
- **Dynamic sitemap:** rewrite `src/app/sitemap.ts` to read published posts + projects + static routes from the DB (replaces hardcoded list). Keep `robots.ts`.
- **GEO:** `/llms.txt` (+ `/llms-full.txt`) route describing the site and listing posts/projects for LLM crawlers; ensure semantic headings + clean content structure on detail pages.
- **OG images:** `src/app/blog/[slug]/opengraph-image.tsx` & `src/app/projects/[slug]/opengraph-image.tsx` via `next/og` `ImageResponse` (title + branding). Fallback site-wide OG.
- **Structured data:** Person (existing) + `Blog`/`ItemList` on listings + breadcrumbs on detail pages; validate with Rich Results.
- **Revalidation:** confirm `revalidatePath`/tag on publish so cached pages refresh; set sensible `revalidate` on public reads.
- **Deploy:** Vercel project, set all env vars (DB, Supabase, AUTH_*, ADMIN_*, PAGESPEED, SITE_URL), connect repo/branch, deploy; point domain. Final `npm run build`.

## Out of scope
New features — M6 is hardening + ship.

## Acceptance tests
1. `/sitemap.xml` lists every published post & project + static routes.
2. `/llms.txt` returns a valid summary + content index.
3. OG image renders for a sample post and project (`/blog/<slug>/opengraph-image`).
4. Rich Results test validates Person + BlogPosting + CreativeWork + breadcrumbs.
5. PSI/Lighthouse SEO ≈ 100 on home + a detail page.
6. Production smoke test on Vercel: public site, login, dashboard, create/publish a post, edit a link — all work live.

## Gate (exit)
Tests pass → project complete (v1 shipped).

## Human steps required
Vercel account + project import; add env vars; (optional) custom domain DNS.
